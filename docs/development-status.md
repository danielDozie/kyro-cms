# Development Status

Thank you for your interest in Kyro CMS! 

Please be aware that Kyro CMS is currently in **active development** and has not yet reached a stable `v1.0` release. 

## What does this mean?

While we are working hard to make Kyro CMS the most powerful Astro-native headless CMS, it is currently in a pre-release phase. This means:

- **Breaking Changes:** APIs, configuration formats, and database schemas may change between minor versions without backward compatibility.
- **Bugs and Issues:** You may encounter bugs, incomplete features, or unoptimized performance in certain areas.
- **Documentation:** Our documentation is still being written and may not cover all features or edge cases.

## Is it ready for production?

**Not yet.** We strongly advise against using Kyro CMS for mission-critical production applications at this time. 

However, we encourage you to:
- Use it for side projects, prototypes, and experiments.
- Test its features and build local applications.
- Provide feedback, report bugs, and contribute to our GitHub repository.

We are actively working towards a stable `v1.0` release. Stay tuned for updates and check our [Changelog](/changelog) for the latest improvements.
